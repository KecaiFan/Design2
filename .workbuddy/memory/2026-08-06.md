## Vercel 构建报错修复（.bin/vite Permission denied, exit 126）
- 现象：Vercel build 报 `sh: .../xcsc-site/node_modules/.bin/vite: Permission denied`，`npm run build` 退出码 126。`Previous build caches not available` 仅为提示，非根因。
- 根因（修正）：Vercel 项目根目录实际设为 `xcsc-site`，所以它直接跑 `xcsc-site/package.json` 的 `build`（`vite build`），而非根目录包装脚本。`.bin/vite` 在 Vercel 冷安装（Previous build caches not available）时丢失 exec bit → Permission denied。之前根目录包装脚本的改动没被用到。
- 修复：改 `xcsc-site/package.json` 的 build 为 `node node_modules/vite/bin/vite.js build`（绕过 .bin 权限）；根 `package.json` 同步成 `cd xcsc-site && npm install && node node_modules/vite/bin/vite.js build && rm -rf "$(cd .. && pwd)/dist" && cp -r dist "$(cd .. && pwd)"`。本地 `npm run build` 验证：`✓ built in 655ms`，出包正常（此前本地失败是 WorkBuddy 的 genie-safe-delete 拦截 trash dist，Vercel 无此问题，忽略）。
