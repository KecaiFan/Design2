## Vercel 构建报错修复（.bin/vite Permission denied, exit 126）
- 现象：Vercel build 报 `sh: .../xcsc-site/node_modules/.bin/vite: Permission denied`，`npm run build` 退出码 126。`Previous build caches not available` 仅为提示，非根因。
- 根因：根目录 `package.json` 的 build 脚本 `cd xcsc-site && npm install && npm run build ...`，内部 `npm run build` = `vite build`，依赖 `node_modules/.bin/vite` 的可执行权限；Vercel 的 FS 上该 bin 脚本丢失 exec bit，导致直接 Permission denied。
- 修复：根 `package.json` 的 build 改为用 node 直接跑 vite 入口，绕过 .bin 权限：`... && node node_modules/vite/bin/vite.js build && rm -rf "$(cd .. && pwd)/dist" && cp -r dist "$(cd .. && pwd)"`。`xcsc-site/package.json` 自身 `build: vite build` 不动（本地照常）。已验证 `xcsc-site/node_modules/vite/bin/vite.js` 存在。
