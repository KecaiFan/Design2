## 修复横向时间线末张卡片被裁切
- 现象：时间线卡片增加到 8 条后，滑到最右"至今"卡片显示不全（右侧被 overflow:hidden 裁掉）。
- 第一次错误修复：把 distance 改成 `railEl.scrollWidth - railEl.parentElement.clientWidth`。无效——`clientWidth` 本身含 padding，几乎等同 `el.clientWidth`，所以没起作用。用户反馈"还是显示不全"。
- 根因修正：rail 起点并非贴着 `.tl` 左缘，而是被 `.tl__inner.shell` 的**左内边距 + 居中 margin** 向内偏移了 `PL`（叫 railLeft）。按整宽位移会少推 `2*PL`，末卡右缘停在内边距内被裁。`.shell` 是 `max-width + margin:0 auto + padding-inline`，所以 railLeft 含居中偏移，不能假设为 gutter。
- 第二次修复（`xcsc-site/src/components/About.jsx`）：运行时用 offsetLeft 链算出 rail 相对 `.tl` 的真实左偏移 `railLeft`，distance 改为 `railEl.scrollWidth - (el.clientWidth - 2 * railLeft)`，使末卡右缘停在距 `.tl` 右缘 `railLeft` 处，与首卡左 inset 对称、完全可见。进度条 scrollTrigger 共用同一 distance()。
- 未提交（用户自行 git push）。
